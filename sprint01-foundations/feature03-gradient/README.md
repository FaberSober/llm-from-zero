# Feature 03 - Gradient

## 1. 本章目标

理解梯度如何描述 Loss 对预测值的变化方向和变化速度，并能手工计算一个最小例子的梯度。

本章只研究：

- Loss 对预测值的导数；
- 梯度的正负和大小分别代表什么；
- 用一个小实验验证导数公式。

本章暂不实现 Chain Rule、Backpropagation 或 Gradient Descent。

## 2. 这是什么

Loss 告诉我们“预测错了多少”，Gradient 告诉我们“预测值往哪个方向变化，Loss 会下降得更快”。

在只有一个预测值的情况下，梯度就是一个数：

- 梯度为负：预测值增加时，Loss 会在当前位置附近下降；
- 梯度为正：预测值减少时，Loss 会在当前位置附近下降；
- 绝对值越大：Loss 对预测值越敏感。

梯度描述的是当前位置附近的局部变化，不是对整个函数的长期预测。

## 3. 为什么需要它

只知道 Loss 的大小，还不能知道下一步应该怎样调整预测值。梯度提供了可执行的方向信息，为后续计算参数梯度和更新参数做准备。

注意：梯度本身不会自动更新任何参数。本章只计算和解释梯度。

## 4. 核心原理

对一个预测值和目标值，使用平方误差：

$$
L=(\hat{y}-y)^2
$$

对预测值求导：

$$
\frac{\partial L}{\partial \hat{y}}=2(\hat{y}-y)
$$

如果是包含多个样本的均方误差，则第 `i` 个预测值对应的梯度为：

$$
\frac{\partial L}{\partial \hat{y}_i}
=\frac{2}{n}(\hat{y}_i-y_i)
$$

本 Feature 使用一个样本，因此 `n=1`，代码直接实现平方误差的导数。

## 5. 手工计算

取：

- 预测值 `ŷ = 1.5`
- 目标值 `y = 2.0`

计算过程：

1. 误差：`ŷ - y = -0.5`
2. Loss：`(-0.5)² = 0.25`
3. 梯度：`2 × (-0.5) = -1.0`

梯度为 `-1.0`，表示在当前位置增加预测值，会让 Loss 下降。实际比较也能看到：

- 预测值增加到 `1.6`，Loss 为 `0.16`；
- 预测值减少到 `1.4`，Loss 为 `0.36`。

## 6. 输入与输出

输入：

- 一个预测值 `prediction`；
- 一个目标值 `target`。

输出：

- 当前平方误差 `loss`；
- 解析公式计算出的 `gradient`；
- 用有限差分近似得到的梯度，用于验证公式；
- 预测值向两个方向小幅变化后的 Loss。

## 7. 运行 Demo

在本目录执行：

~~~bash
uv run python main.py
~~~

预期输出：

~~~text

~~~

其中，有限差分只是为了用可运行的小实验检查导数公式；实际训练会使用解析梯度。

## 8. 在 LLM 中的作用

LLM 会先根据输入预测下一个 Token，再用 Loss 衡量预测与真实 Token 的差异。Loss 对模型输出的梯度会继续通过 Chain Rule 和 Backpropagation 传到各层参数，供后续参数更新使用。

本章只覆盖这条链路的起点：Loss 对预测值的局部变化。如何把这个梯度传到参数，将在后续 Feature 学习。

## 9. 常见误区

- Loss 小不代表梯度一定小，函数形状还会影响变化速度；
- 梯度不是 Loss，也不是参数更新量；
- 梯度的正负表示局部下降方向，绝对值表示局部敏感程度；
- 导数描述局部变化，不能把一个点的梯度直接当成全局规律；
- 本例是平方误差的单样本版本，多样本均方误差还要包含 `1/n`。

## 10. 我需要记住什么

1. Gradient 是 Loss 对某个变量的变化率。
2. 梯度为负时，增加该变量通常会让当前位置附近的 Loss 下降。
3. 梯度为正时，减少该变量通常会让当前位置附近的 Loss 下降。
4. 梯度只提供方向和变化速度，不负责执行更新。
5. 对平方误差 `L=(ŷ-y)²`，有 `∂L/∂ŷ=2(ŷ-y)`。

## 14. 知识点说明

- 核心概念：Gradient 是 Loss 对变量的导数，描述局部变化方向和变化速度。
- 关键公式：平方误差 `L=(ŷ-y)²`；其对预测值的梯度为 `∂L/∂ŷ=2(ŷ-y)`。
- 判断方法：梯度为负，增加预测值会让当前位置附近的 Loss 下降；梯度为正时则相反。
- 实验关系：`prediction=1.5`、`target=2.0` 时，Loss 为 `0.25`，梯度为 `-1.0`。
- 边界：本 Feature 不计算参数梯度，不执行参数更新，也不展开 Chain Rule。
