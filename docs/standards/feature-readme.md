# Feature README 规范

Feature README 同时是 GitHub 上的项目说明和在线教材章节。每个 Feature 只解决一个核心知识问题。

## 推荐结构

~~~markdown
# Feature 名称

## 1. 本章目标
## 2. 这是什么
## 3. 为什么需要它
## 4. 核心原理
## 5. 数学表示
## 6. 手工计算
## 7. 最小代码实现
## 8. 实验
## 9. 在 LLM 中的位置
## 10. 常见误区
## 11. 本章需要记住什么
## 12. 配套代码
## 13. 前置知识
## 14. 下一章
## 15. 知识点说明
~~~

章节可以根据实际内容合并或省略部分小节，但必须保持以下内容完整：

- 学习目标和核心概念；
- 计算流程和必要公式；
- 输入、输出和可运行命令；
- 示例与实际代码一致；
- 该知识点在神经网络或 LLM 中的作用；
- 3～5 条复习结论；
- 可作为知识卡片素材的知识点说明。

## 编写边界

1. 先阅读并运行当前 Feature 的代码，再修改 README。
2. 不虚构公式、输出、历史或实验结果。
3. 不提前替代后续 Feature 的教学内容。
4. 不修改无关 Feature。
5. 使用 UV 命令运行 Python 示例。
6. 保留正确的图片和相对链接。
