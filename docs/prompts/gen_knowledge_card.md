# 知识卡片生成规范

请根据我提供的「知识点内容」，生成一张统一风格的技术知识卡片图片。

## 一、图片规格

* 竖版知识卡片。
* 比例约为 4:5。
* 推荐尺寸约 1120 × 1400 px。
* 高清输出，文字必须清晰可读。
* 整张图片只讲解一个核心知识点。
* 使用简体中文。
* 常见专业术语可以使用「中文（English）」形式，例如：

  * 损失函数（Loss）
  * 梯度（Gradient）
  * 前向计算（Forward Computation）

## 二、整体视觉风格

采用现代、专业、清晰的「技术教材 + 信息图知识卡片」风格。

视觉要求：

* 白色或极浅灰背景；
* 蓝色作为主要视觉色；
* 绿色、紫色、黄色、红色作为辅助模块色；
* 卡片式布局；
* 中等圆角；
* 轻微阴影；
* 清晰的模块边界；
* 保持适当留白；
* 不使用复杂纹理；
* 不使用写实人物；
* 不使用无关装饰插画；
* 不做营销海报风；
* 不使用过度渐变、霓虹、3D 效果；
* 整体接近高质量计算机科学教材的信息图风格。

要求视觉统一、专业、适合长期组成一套 AI / LLM 学习知识卡片。

## 三、标题区域

顶部为完整宽度标题区。

包含：

1. 知识点图标；
2. 中文知识点名称；
3. 英文名称；
4. 一句非常简短的知识点描述。

例如：

「前向计算（Forward Computation）」

副标题：

「线性单元如何把输入变成预测值」

标题字号明显大于正文。

## 四、核心流程图区域

左上区域为整张知识卡片最重要的视觉区域，占较大面积。

根据当前知识点绘制：

* 流程图；
* 数据流；
* 节点关系；
* 数学计算过程；
* 模型结构；
* 输入 → 处理 → 输出关系。

尽量通过箭头、节点、模块框、数字示例帮助理解。

要求：

* 流程方向明确；
* 节点之间关系清楚；
* 每个关键步骤都有短标签；
* 不堆砌文字；
* 优先「图形解释」而不是「文字解释」。

如果知识点适合数学表达，在流程图下方单独展示核心公式。

数学公式必须清晰、正确、醒目。

## 五、右侧知识解释

右侧使用多个小型知识卡片解释核心概念。

优先包含：

### 这是什么？

用 2～4 句简短文字解释知识点定义。

### 为什么需要它？

解释该知识点解决什么问题，以及为什么模型需要它。

### 核心原理

使用 3～5 个简短要点说明机制。

尽量使用：

「输入 → 处理 → 输出」

的逻辑解释，而不是抽象理论堆砌。

## 六、最小示例

在中下部设置「最小示例」区域。

使用一个非常简单、可以人工计算或直观看懂的例子。

包括：

* 输入；
* 参数；
* 计算过程；
* 输出结果。

示例的目的不是展示复杂能力，而是让初学者理解核心机制。

如果涉及数学公式，优先使用简单数字。

## 七、在神经网络 / LLM 中的作用

单独设置一个区域说明：

「这个知识点在神经网络或 LLM 中出现在哪里？」

优先列出 3～5 个典型场景。

例如：

* Linear Layer
* Embedding
* Attention
* Output Layer
* Transformer

根据当前知识点实际情况调整，不强行填写无关内容。

## 八、历史来源

设置一个较小的「历史来源」模块。

简要说明：

* 概念最早来源；
* 重要人物；
* 重要论文；
* 重要发展阶段；
* 后来如何进入现代深度学习 / LLM。

控制篇幅，只保留帮助建立知识体系的关键历史节点。

如果历史来源不明确，不虚构具体人物或年代。

## 九、常见知识点

设置「常见知识点」区域。

使用标签或短词形式展示与当前知识点直接相关的概念。

例如：

输入（Input）

权重（Weight）

偏置（Bias）

预测值（Prediction）

损失（Loss）

梯度（Gradient）

参数更新（Parameter Update）

只保留真正相关的概念。

## 十、需要记住

底部设置醒目的「需要记住」区域。

总结 3～5 条最重要结论。

每条一句话。

这是用户以后快速复习时最重要的区域。

应该做到：

「只看这一部分，也能快速回忆这个知识点。」

## 十一、内容原则

整张卡片遵循以下原则：

1. 面向正在从零学习 AI / LLM 的开发者；
2. 技术准确优先于视觉效果；
3. 一个卡片只解释一个核心概念；
4. 使用最简单的例子解释抽象概念；
5. 优先使用流程图，而不是长篇文字；
6. 中文正文尽量短；
7. 专业英文术语保留英文名称；
8. 数学公式必须正确；
9. 模块之间逻辑关系明确；
10. 不为了填满版面而添加无关信息。

## 十二、视觉层级

信息重要程度：

核心流程图

>

核心公式

>

概念解释

>

最小示例

>

需要记住

>

LLM 中的作用

>

相关知识点

>

历史来源

不要让历史介绍或辅助信息抢占核心流程图的视觉注意力。
